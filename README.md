# 🥗 6-sinf Tabiiy Fanlar: Ratsional Ovqatlanish va Hazm Qilish Sistemasi

Ushbu loyiha 6-sinf o'quvchilari, biologiya va tabiiy fanlar o'qituvchilari uchun mo'ljallangan zamonaviy, interaktiv, ko'rgazmali raqamli ta'limiy veb-platformadir.

---

## 🌟 Asosiy Xususiyatlar va Imkoniyatlar

1. **Muvozatlashgan (Ratsional) Ratsion:**
   - Oqsillar, uglevodlar, yog'lar, vitamin va minerallarning organizmdagi o'rni va sutkalik me'yorlari.
   - Har bir ozuqa moddasining tabiiy manbalari.

2. **🍽️ Garvard "Sog'lom Tarelka" Modeli:**
   - Rangli, interaktiv sektorli tarelka diagrammasi (50% sabzavot-mevalar, 25% to'liq donlar, 25% sog'lom oqsillar).

3. **⚡ Shaxsiy Kaloriya va BJU Kalkulyatori:**
   - O'quvchining yoshi, jinsi, vazni va faollik darajasi bo'yicha sutkalik kaloriya hamda oqsil, yog', uglevod miqdorini aniq hisoblab beruvchi kalkulyator.

4. **🔬 Inson Ovqat Hazm Qilish Tizimi (Interaktiv yo'l):**
   - Og'iz bo'shlig'i ➡️ Qizilo'ngach ➡️ Oshqozon ➡️ Ingichka ichak ➡️ Jigar va bezlar ➡️ Yo'g'on ichak.
   - Har bir a'zoning animatsiyalari, hazm qilish muddatlari, fermentlari va qiziqarli biologik faktlar.
   - Ovozli eshittirish (Web Speech API) imkoniyati.

5. **🐾 Hayvonlarning Ovqat Hazm Qilish Sistemasi Taqqoslovi:**
   - O'txorlar (Qoramol: 4 xonali murakkab oshqozon — Kaltak, To'r, Qatqorin, Shirdon).
   - Go'shtxorlar (Sher: Kuchli kislotali 1 xonali oshqozon, qisqa ichak).
   - Hammaxorlar (Inson, ayiq: universal hazm).

6. **🎮 "Sog'lom Tarelka" Mini-O'yini:**
   - Bolalar uchun foydali va zararli mahsulotlarni saralash orqali to'g'ri odatlarni shakllantiruvchi o'yin (ball tizimi bilan).

7. **💧 Kunlik Suv Balansi Trekeri:**
   - 8 stakanlik vizual suv hisoblagichi.

8. **📝 6-sinf Bilimni Mustahkamlash Testi:**
   - Fikr-mulohazali va tushuntirishlarga ega 5 ta test savoli, ball va rag'batlantiruvchi medallar.

9. **🎨 Dizayn va Qulaylik:**
   - Qorong'i (Dark) va Yorug' (Light) mavzular.
   - Tovush effektlari.
   - Barcha smartfon va planshetlarga mos (Fully Responsive).

## 🚀 Ishga Tushirish

Hech qanday qo'shimcha o'rnatish shart emas! Shunchaki `index.html` faylini istalgan brauzerda (Chrome, Edge, Firefox, Safari) ochishingiz mumkin.

## 🌐 GitHub Pages orqali Onlayn Ishga Tushirish
1. Ushbu loyihani GitHub reposiga yuklang.
2. Repo sozlamalariga kiring: **Settings** -> **Pages**.
3. **Branch** bo'limida `main` (yoki `master`) ni tanlab, **Save** tugmasini bosing.
4. Saytingiz bepul onlayn URL orqali butun dunyoga ko'rinadi!
